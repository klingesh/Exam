## 📝 Answering technique

1. **Lead with the definition.** One crisp sentence — examiners look for the keyword.
2. **Then name the framework and list its parts.** Structured answers beat paragraphs every time.
3. **Then one example.** A company name or a one-line illustration proves understanding rather than memorisation.
4. **Match the length to the marks.** 2 marks = definition + a line. 5 marks = definition + framework + example. 10 marks = add advantages, limitations and a diagram.
5. **Expand every abbreviation the first time** you use it — TNA, ADR, MBO, BARS, POSH.
6. **For any "difference between" question, use a table.** Faster to write, easier to mark.
