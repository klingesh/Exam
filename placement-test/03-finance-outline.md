## ⭐ IMPORTANT TO NOTE

### Must-know formulas

**Ratios**
```
Current Ratio          = Current Assets / Current Liabilities
Quick Ratio            = (Current Assets – Inventory) / Current Liabilities
Debt-Equity Ratio      = Debt / Equity
Gross Profit Ratio     = Gross Profit / Sales × 100
Net Profit Ratio       = Net Profit / Sales × 100
Inventory Turnover     = Cost of Goods Sold / Average Inventory
Debtors Turnover       = Credit Sales / Average Debtors
Return on Equity       = Net Profit after Tax / Shareholders' Funds × 100
EPS                    = Profit available to equity holders / Number of equity shares
P/E Ratio              = Market Price per Share / EPS
```

**Marginal costing & break-even**
```
Contribution        = Sales – Variable Cost
P/V Ratio           = Contribution / Sales × 100
BEP (units)         = Fixed Cost / Contribution per unit
BEP (value)         = Fixed Cost / P/V Ratio
Margin of Safety    = Actual Sales – Break-Even Sales
Required Sales      = (Fixed Cost + Desired Profit) / P/V Ratio
```

**Depreciation**
```
Straight Line = (Cost – Scrap Value) / Useful Life
WDV           = Book Value × Rate
```

**Capital budgeting**
```
Payback Period  = Initial Investment / Annual Cash Inflow
ARR             = Average Profit / Average Investment × 100
NPV             = Present Value of Inflows – Initial Investment
PI              = PV of Inflows / Initial Investment
IRR             = the rate at which NPV = 0
```

**Leverage**
```
Operating Leverage (DOL) = Contribution / EBIT
Financial Leverage (DFL) = EBIT / (EBIT – Interest)
Combined Leverage (DCL)  = DOL × DFL  =  Contribution / (EBIT – Interest)
```

**Working capital**
```
Working Capital  = Current Assets – Current Liabilities
Operating Cycle  = Inventory period + Debtors period – Creditors period
```

### Decision rules — memorize the direction
| Method | Accept when |
|---|---|
| **NPV** | NPV > 0 |
| **IRR** | IRR > cost of capital |
| **PI** | PI > 1 |
| **Payback** | shorter than the cut-off period |
| **ARR** | higher than the required rate |
