# 1️⃣6️⃣ ANALOGY 🟢

⏱️ **Study time: 20 minutes** | 🎯 **Typical questions: 2–4**

> 🟢 **EASY MARKS.** An analogy question asks: *"A is to B as C is to ?"* — you find the **relationship** between the first pair and apply the identical relationship to the second pair. There is nothing to memorize except a list of relationship types.

---

## 📖 PART 1 — THE METHOD ⭐

```
STEP 1:  Build a SENTENCE that links the first pair.
STEP 2:  Make the sentence as SPECIFIC as you can.
STEP 3:  Apply the SAME sentence to the second pair.
STEP 4:  Check the ORDER matches.
```

### 🔍 Example 1 — See the method in action
*Doctor : Hospital :: Teacher : ?*
```
Step 1: Build a sentence. "A doctor works in a hospital."
Step 2: Make it specific. "A doctor is a professional whose WORKPLACE is a hospital."
Step 3: Apply it: "A teacher is a professional whose workplace is a ____."
        → SCHOOL
✅ School
```

### 🚨 THE #1 RULE: make your sentence SPECIFIC
A vague sentence lets multiple options fit, and the exam always includes a near-miss option to punish that.

```
Question:  Cow : Calf :: Horse : ?
Options:   (a) Stable  (b) Foal  (c) Mare  (d) Grass

VAGUE sentence:    "A cow is related to a calf."
   → Options (a), (b) and (c) all seem "related". You're stuck.

SPECIFIC sentence: "A calf is the YOUNG ONE of a cow."
   → Only FOAL is the young one of a horse.
   → (c) Mare is a female horse, not a young one. Trap avoided.
✅ (b) Foal
```

### 🚨 THE #2 RULE: watch the ORDER
```
Cow : Calf   →  adult : young
so the answer must also be   adult : young

If the question were  Calf : Cow :: Foal : ?  →  the answer is HORSE.
Same relationship, reversed order.
```

## 📖 PART 4 — NUMBER ANALOGIES ⭐

Same idea, but the relationship is arithmetic. **Test these operations in order:**

```
1. Is it a SQUARE or CUBE?        4 : 16   →  n²
2. Is it a fixed MULTIPLE?         5 : 20   →  × 4
3. Is it ADD / SUBTRACT?           7 : 12   →  + 5
4. Is it n² + 1 or n² – 1?         5 : 24   →  n² – 1
5. Is it a REVERSAL of digits?    34 : 43
6. Is it a PRIME sequence?         3 : 5    →  the next prime
```

### 🔍 Example 2
*8 : 64 :: 9 : ?*
```
Step 1: What links 8 to 64?  Test: 8² = 64 ✔  (also 8 × 8)
Step 2: Apply to 9: 9² = 81
✅ 81
```

### 🔍 Example 3 — When the first guess fails
*7 : 50 :: 9 : ?*
```
Step 1: Try × something. 50/7 isn't clean. ✘
Step 2: Try n². 7² = 49. Close to 50! So it's n² + 1 ✔
Step 3: Apply: 9² + 1 = 81 + 1 = 82
✅ 82
```
> 💡 **When a square is "just off", check n² ± 1 or n² ± 2.** That's the most common number-analogy pattern after plain squares.

### 🔍 Example 4 — Cubes
*2 : 8 :: 3 : ?*
```
Step 1: 2 → 8 could be × 4 OR 2³. Ambiguous!
Step 2: Check the options. If 27 is an option, it's cubes. If 12 is an option, it's × 4.
        (This is why you should always glance at the options first.)
✅ 27 (if cubes)
```

## 📖 PART 5 — LETTER ANALOGIES

Use the alphabet position numbers from [14-alphabet-series.md](14-alphabet-series.md).

### 🔍 Example 5
*AB : CD :: EF : ?*
```
Step 1: Positions. AB = (1,2), CD = (3,4). Each letter shifted by +2.
Step 2: EF = (5,6). Add 2 to each → (7,8) = GH
✅ GH
```

### 🔍 Example 6
*ACE : BDF :: GIK : ?*
```
Step 1: ACE = (1,3,5). BDF = (2,4,6). Each letter +1.
Step 2: GIK = (7,9,11). Add 1 to each → (8,10,12) = HJL
✅ HJL
```

## ⚡ SHORTCUTS & SPEED TRICKS

1. **Build a SENTENCE. Make it SPECIFIC.** This alone solves most analogy questions.

2. **Check the ORDER.** Adult : young must map to adult : young, not young : adult.

3. **Glance at the OPTIONS before deciding the relationship.** The options often reveal which of two possible relationships is intended (see Example 4).

4. **If two options both fit, your sentence isn't specific enough.** Go back and add a detail.

5. **Eliminate the "same category" distractor.** For *Cow : Calf :: Horse : ?*, options like "Mare" and "Stable" are horse-related but relationship-wrong. Being about the right animal is not the same as being the right relationship.

6. **For number analogies, test in this order:** square → cube → multiple → add/subtract → n²±1 → digit reversal.

7. **For letter analogies, convert to numbers immediately.**

8. **Don't overthink.** Analogy questions are meant to take 15–20 seconds each. If one is taking a minute, mark it and move on.

## 🎯 QUICK RECAP — say these out loud

- **Build a sentence. Make it SPECIFIC.** Then apply it to the second pair.
- **Check the ORDER** of the relationship
- Run through the **20 relationship types** when stuck
- **Glance at the options** — they disambiguate the intended relationship
- If two options fit, your sentence was **too vague**
- Numbers: test **square → cube → multiple → add → n²±1 → reversal**
- Letters: **convert to position numbers** first
- Beware the **"right topic, wrong relationship"** distractor
- These should take **15–20 seconds each.** Don't linger.
